Unity MCP for ALCOM

CoplayDev Unity MCPをALCOMでインストール・更新するためのVPMリポジトリです。Unity側と同じ版のローカル接続サーバーを同梱しています。

ALCOMに追加

手動で追加する場合は、ALCOMの「パッケージ管理」→「リポジトリを追加」に次のURLを入力してください。

https://r-fallingstar.github.io/unity-mcp-alcom/index.json

追加後、プロジェクトのパッケージ一覧から「MCP for Unity (ALCOM)」を選びます。ベータ版はALCOMのプレリリース表示を有効にしてください。更新・導入時は対象のUnityプロジェクトを閉じてください。

Python 3.10以上とuvが必要です。接続設定を明示的に上書きしている場合は、その設定が優先されます。既存の手動配置パッケージからの移行手順はREADMEをご覧ください。
